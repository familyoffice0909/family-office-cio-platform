# Sprint v3.2.0 — Risk Budget Intelligence

## Implementation Manifest

**Status:** Approved by CIO  
**Lifecycle phase:** Phase C — Controlled Implementation  
**Baseline:** v3.1.0 — Portfolio Scenario Intelligence  
**Branch:** `feature/v3-2-0-risk-budget-intelligence`

## Objective

Introduce portfolio-level Risk Budget Intelligence by consuming the governed
outputs of Portfolio Optimization Intelligence, Portfolio Scenario
Intelligence, existing portfolio-risk controls, and exposure attribution.

The sprint must not replace upstream recommendation, optimization, scenario,
exposure, or risk-scoring authority.

## Approved File Scope

| File | Action | Purpose |
|---|---|---|
| `RiskBudgetIntelligence.js` | New | Evaluate portfolio allocations against governed risk budgets and produce deterministic risk-budget decisions. |
| `AutonomousCioOrchestrator.js` | Modify | Execute Risk Budget Intelligence after Portfolio Scenario Intelligence. |
| `ExecutiveReportingEngine.js` | Modify | Surface risk-budget status, utilization, breaches, and directive. |
| `ModuleRegistry.js` | Modify | Register the new module. |
| `Config.js` | Extend only if required | Declare worksheet names or governed configuration not already available. |
| `WorksheetSchemaRegistry.js` | Extend only if required | Register authoritative worksheet contracts introduced by the sprint. |
| `PortfolioOptimizationIntelligence.js` | Reuse | Remains authoritative for optimized allocation outputs. |
| `PortfolioScenarioIntelligence.js` | Reuse | Remains authoritative for preferred-scenario context. |
| `tests/risk-budget-intelligence.test.js` | New | Validate deterministic risk-budget calculations and contracts. |
| `tests/risk-budget-integration.test.js` | New | Validate registry, orchestration, configuration, and reporting integration. |

## Scope Controls

- No duplicate portfolio optimizer.
- No duplicate scenario engine.
- No replacement of existing portfolio-risk scoring.
- No predictive return, volatility, or loss forecasting.
- No trade execution or cash-quantity calculation.
- Existing upstream constraints remain authoritative.
- Backward compatibility with the certified v3.1.0 baseline is mandatory.

## Expected Outcome

Risk Budget Intelligence should provide:

- governed risk-budget capacity;
- current and proposed budget utilization;
- remaining risk capacity;
- budget status and breach count;
- constrained candidates or allocations;
- executive risk-budget directive and rationale.
